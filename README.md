## Summary
Felpudo e Fofuxa is a mini-project developed using Unity and C#, designed to practice Unity 2D and Parallax effects. In this game, you control Felpudo, with the goal of dodging obstacles, shooting enemies and defeat Uruca to rescue Fofuxa!
![Points](Assets/Midia/ENEMY.gif)

## KeyBinds
