# Felpudo e Fofuxa - Flappy Bird
## [!IMPORTANT] Unity Version: 6000.3.7f1
>  Digital games students Brenda Santos Pinheiro and Thiago Lopes, from UNEB, set out to create a minigame for their Game Programming course.
> [Game demonstration Video.](https://youtu.be/awM6dHQyho4)

![Win](Assets/Midia/BOSS.gif)

## Summary
Felpudo e Fofuxa is a mini-project developed using Unity and C#, designed to practice Unity 2D and Parallax effects. In this game, you control Felpudo, with the goal of dodging obstacles, shooting enemies and defeat Uruca to rescue Fofuxa!
![Points](Assets/Midia/ENEMY.gif)

## KeyBinds

| Ação | Tecla |
|---|---|
| Pular | Space |
| Atirar | Left Mouse |
| Pausar | Esc |
